# KH Wood search and site audit — 8 October 2026

## Executive summary

The public site has a clear navigation path to its twelve main pages and generally unique page titles and descriptions. The most serious search-readiness gaps were a missing XML sitemap, no canonical tags, two live hostnames serving the same content, and no H1 on the products overview. This change addresses those gaps and adds a curated product gallery. Google Search Console remains the source of truth for actual indexing and search performance after publication.

## Findings and changes

| Priority | Finding and evidence | Action |
| --- | --- | --- |
| High | `https://khodeer.com/sitemap.xml` returned 404; live `robots.txt` had no sitemap reference. | Added `/sitemap.xml` from the public route and product slug lists, plus `/robots.txt` with the sitemap URL. |
| High | `khodeer.com` and `www.khodeer.com` both returned page content; no rendered page had a canonical tag. | Fixed the canonical origin to `https://khodeer.com`, added self-referencing canonical URLs, and added a permanent `www` redirect. |
| Medium | `/products` had no H1 in the rendered HTML. | Added a descriptive H1 while retaining the page's visual treatment. |
| Medium | The site used a request-derived metadata origin. On `www`, social image URLs changed host. | Set a fixed trusted origin and page-specific Open Graph URL, title, and description. |
| Medium | No Organization or breadcrumb structured data was visible in the rendered HTML. | Added minimal Organization data on the homepage and BreadcrumbList data on each range page. Product offers, ratings, and stock availability were deliberately omitted because the site does not publish verified values. |
| Medium | The gallery source folder held 28 mixed JPEG/HEIC photos, including similar views; the full folder was about 13 MB. | Selected 12 distinct views and created WebP copies totaling roughly 2.1 MB. Images below the fold load lazily with dimensions and descriptive alt text. |

## Remaining optimization work

1. **Measure real user performance after deployment.** Review Search Console Core Web Vitals and PageSpeed Insights for home, products, and a range page on mobile. The homepage includes a long animated hero and several videos. Avoid changing that experience based only on a synthetic score; use LCP, INP, and CLS evidence to find the costly element first.
2. **Reduce weight of existing media.** `public/assets/K5_day.png` is about 5 MB and `decision-route-video.mp4` about 6 MB. Serve sized modern image variants and compare a smaller video encode or a still poster where motion is not essential. Existing image optimization is disabled in `next.config.ts`, so responsive source files need to be generated and wired explicitly unless the deployed image transformer is made reliable.
3. **Revisit HTML caching.** Live public HTML currently returns `cache-control: no-store, must-revalidate`. Cache stable marketing pages at the hosting layer if the platform supports it, while preserving fresh content where the partners page displays market signals. Measure TTFB before and after any cache change.
4. **Deepen product range content with verified facts.** The range pages explain buying considerations but offer few concrete product specifications. Add confirmed species, grades, dimensions, panel types, standards, delivery coverage, and original photos when the commercial team can verify them. Avoid generic keyword filler or unsupported certification and stock claims.
5. **Review business trust details.** Keep office locations, contact details, brand relationships, and any Google Business Profiles consistent with the operating business. Add policy or company details only where they genuinely apply.

## Search Console handoff

After the updated Site is live, inspect `https://khodeer.com/robots.txt` and `https://khodeer.com/sitemap.xml`, submit the sitemap to the `khodeer.com` property, and use URL Inspection on `/`, `/products`, and one range page. Check that Google-selected canonical matches the declared apex URL. Indexing and rich results remain Google's decision; valid crawl files are prerequisites, not a guarantee.

## Audit limits

This review used repository code, local rendered output, and live HTTP responses. It did not include Search Console access, analytics, a backlink review, or real-user Core Web Vitals. The live responses reported here were observed before publication of these changes.
